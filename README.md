# paceghost-io-core

This repository contains core public assets and documentation for [Paceghost.io](https://www.paceghost.io), a platform for monitoring and optimizing website visibility in the era of AI-powered search.

### What you'll find here:
- ✅ Sample `robots.txt` files to control AI crawler access
- ✅ Site ownership verification methods (via `.txt` or JS snippet)
- ✅ Lists of known AI user agents
- ✅ Structured data formats for LLM visibility

For full site scans, visibility reports, or to test your setup, visit [https://www.paceghost.io](https://www.paceghost.io).
